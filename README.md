🌍📘 Arabic-to-English PDF Translator

✨ Translate scanned or image-based Arabic PDFs into English while keeping the original layout intact (tables, images, and formatting preserved).

🚀 Features

✅ OCR Arabic text from scanned/image PDFs
✅ Translate line-by-line to English with NLLB-200
✅ Preserve tables, images, text alignment, and formatting
✅ Export results in PDF (layout-preserved), JSON, and CSV
✅ Works on multi-page documents
✅ Extensible → fallback OCR (Tesseract/PaddleOCR) possible

🛠️ Tech Stack

🤖 OCR: TrOCR (Microsoft)

🌐 Translation: NLLB-200 (Meta)

📄 PDF Processing: PyMuPDF (fitz)

🖊️ Overlay & Export: ReportLab, JSON, CSV
